***1 НАЗНАЧЕНИЕ ПРОГРАММЫ***

Программа «MathQuiz» предназначена для самостоятельной тренировки навыков устного и письменного счета. За один раунд пользователю предлагаются четыре случайных арифметических задания: сложение, вычитание, умножение и деление. На ввод всех ответов отводится 30 секунд.

Программа отображает примеры, принимает числовые ответы, отсчитывает оставшееся время и автоматически проверяет правильность решений. Раунд считается успешно завершенным, если все четыре ответа введены правильно до окончания времени.

***2 УСЛОВИЯ ВЫПОЛНЕНИЯ ПРОГРАММЫ***

Для работы требуется персональный компьютер под управлением Microsoft Windows. Программа разработана как приложение Windows Forms на языке C# для платформы .NET Framework версии 4.7.2. Подключение к Интернету для основных функций не требуется. Специальное периферийное оборудование не используется.

Пользователю необходимы базовые навыки работы с компьютером, мышью и клавиатурой, а также умение вводить целые числа.

***3 ВЫПОЛНЕНИЕ ПРОГРАММЫ***

**3.1 Запуск программы**

Для запуска готового приложения откройте папку с файлом MathQuiz.exe и дважды щелкните по нему левой кнопкой мыши. После запуска появится главное окно с заголовком «Math Quiz». При запуске из Microsoft Visual Studio следует открыть проект и выполнить его запуск средствами среды разработки.
 
**3.2 Описание главного окна**

В главном окне расположены индикатор оставшегося времени, четыре арифметических примера, четыре поля для ответов и кнопка «начать викторину». Первое поле предназначено для ответа на сложение, второе – на вычитание, третье – на умножение, четвертое – на деление. Оставшееся время отображается в области Time Left.

**3.3 Порядок работы с программой**

1. Запустите приложение. До начала раунда вместо числовых примеров могут отображаться знаки вопроса.

2. Нажмите кнопку «начать викторину». Программа сформирует четыре случайных примера и запустит обратный отсчет с 30 секунд.

3. Введите ответы в соответствующие поля: сначала ответ на сложение, затем на вычитание, умножение и деление.

4. Постарайтесь правильно заполнить все четыре поля до истечения времени. Программа проверяет введенные значения автоматически.

5. После завершения раунда ознакомьтесь с сообщением программы. Для новой попытки снова нажмите «начать викторину»: будут сформированы новые примеры.

Во время выполнения раунда кнопка начала викторины недоступна. Повторный запуск становится возможен после завершения текущей попытки.

**3.4 Завершение работы**

Чтобы закрыть программу, нажмите кнопку закрытия окна (×) в заголовке. Отдельная кнопка выхода в интерфейсе не предусмотрена.
 
***4 СООБЩЕНИЯ ОПЕРАТОРУ***

При правильном решении всех четырех заданий до окончания времени программа выводит сообщение «Ты правильно ответил на все вопросы!» с заголовком «Поздравляю!». Нажмите «ОК», чтобы закрыть сообщение.

Если 30 секунд истекли, появляется сообщение «Время вышло!». При незавершенном раунде программа также выводит сообщение «Вы не закончили вовремя.» с заголовком «Извините!». После истечения времени правильные ответы автоматически подставляются в поля, что позволяет проверить результат.

Если кнопка «начать викторину» временно недоступна, это означает, что раунд еще выполняется. Продолжайте вводить ответы; кнопка станет доступна после окончания попытки.

Если приложение не запускается, проверьте наличие файла MathQuiz.exe и установленной среды .NET Framework 4.7.2. Если окно программы перестало отвечать, закройте приложение средствами операционной системы и запустите его повторно. Результаты незавершенного раунда не сохраняются.

***5 РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ***

Перед началом раунда подготовьтесь к вводу ответов и внимательно сопоставляйте каждое поле с соответствующим арифметическим действием. Для успешного завершения необходимо правильно заполнить все четыре поля в течение 30 секунд. При истечении времени используйте показанные программой правильные ответы для самопроверки.

Программа предназначена для тренировочного использования. История попыток, результаты пользователей и статистика прохождения не сохраняются.
